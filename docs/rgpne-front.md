# Application de la charte RGPNE

## Palette

- Bleu institutionnel : `#17418A`
- Bleu clair : `#0095C9`
- Jaune drapeau : `#FFF24B`
- Rouge drapeau/action : `#DB3832`
- Bleu sombre : `#09242E`
- Vert secondaire : `#65B32E`
- Gris texte : `#323230`

## Principes UI

- Header blanc avec logotype institutionnel a gauche.
- Navigation claire : Demande, Suivi, Acces administration.
- Barre tricolore discrete pour rappeler l'identite nationale.
- Footer bleu institutionnel avec coordonnees, acces rapides et liens utiles.
- Formulaire public simple, decoupe en sections comprehensibles.
- Back-office sobre, dense et oriente instruction de dossiers.
- Mobile-first : champs lisibles, boutons larges, sections non surchargees.

## Typographie

Le RGPNE recommande Cooper Hewitt comme typographie principale et Poppins pour les contenus numeriques.
En attendant les fichiers officiels des polices, le frontend declare ces familles avec des fallbacks systeme.
